# Awesome-Agent-Workflow-Platform

# Top Agent Workflow Platform Ecosystem

**Curated List of SaaS Products & Open-Source GitHub Projects**  
*Focused on Visual AI Orchestration, Autonomous Agents & Workflow Automation*  
**Last updated: March 2026**

This repository tracks notable **SaaS platforms** and **open-source projects** for **Agent Workflow Platforms**. These tools enable the design, orchestration, and deployment of AI agents and multi-step workflows that combine LLMs, tools, APIs, and human-in-the-loop approvals for automation across business and technical domains.

**Examples** include Dify, Flowise, LangFlow Cloud, Rivet AI, N8N Cloud, Pipedream, Lindy, Activepieces, BuildShip, and Relay.app (the category leaders).

**Open-source emphasis**: This section is heavily expanded with every major active project for self-hosting, custom agent orchestration, and transparent workflow automation — ideal for developers, AI engineers, and teams building vendor-independent agentic systems.

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## SaaS/Hosted Platforms

- **[Dify Cloud](https://cloud.dify.ai/)**  
  Managed version of the open-source LLM app development platform with visual workflow builder, RAG engine, and agent orchestration for rapid AI application deployment.

- **[Flowise Cloud](https://flowiseai.com/)**  
  Hosted version of the drag-and-drop LLM app builder with LangChain integration, enabling visual construction of chatbots, agents, and RAG systems.

- **[LangFlow Cloud](https://www.langflow.org/)**  
  Managed cloud offering of the visual framework for building multi-agent and RAG applications with LangChain components.

- **[Rivet AI](https://rivetai.io/)**  
  AI-powered workflow platform for content production and creative automation with agent-based task orchestration.

- **[N8N Cloud](https://n8n.io/)**  
  Hosted version of the fair-code workflow automation platform with 400+ integrations and native AI agent capabilities, combining visual automation with LLM orchestration.

- **[Pipedream](https://pipedream.com/)**  
  Code-first event workflow platform with managed auth, MCP server support, and AI agent orchestration for developers building API integrations.

- **[Lindy](https://www.lindy.ai/)**  
  No-code AI agent platform for business automation with pre-built templates for email, scheduling, CRM, and research workflows.

- **[Activepieces Cloud](https://www.activepieces.com/)**  
  Hosted version of the MIT-licensed automation platform with AI-native pieces, clean visual builder, and self-hostable core.

- **[BuildShip](https://buildship.com/)**  
  Low-code visual backend builder with AI workflow orchestration, API generation, and scheduled task automation.

- **[Relay.app](https://www.relay.app/)**  
  Human-in-the-loop automation platform with first-class approval steps, AI-powered workflows, and collaborative playbook design.

## Open-Source GitHub Projects

- **[Dify](https://github.com/langgenius/dify)**  
  Open-source LLM application development platform with 150k+ stars. Combines prompt orchestration, RAG engine, agent workflows, datasets, observability, and a publishable app layer. Apache 2.0 licensed with private deployment support for data-sensitive enterprises .

- **[Flowise](https://github.com/FlowiseAI/Flowise)**  
  Drag-and-drop UI to build LLM apps with LangChain. More product-polished than LangFlow, with 152k+ stars. Best for fastest prototype-to-agent development, though graphs can get messy at scale. Now under Workday ownership .

- **[LangFlow](https://github.com/langflow-ai/langflow)**  
  Visual framework for building multi-agent and RAG applications with 152k+ stars. MIT-licensed, Python-based, with tighter LangChain integration than Flowise. Ideal for engineers who want nodes that feel like code, not magic .

- **[n8n](https://github.com/n8n-io/n8n)**  
  The most popular self-hostable automation platform with 198k+ GitHub stars. 400+ integrations, visual editor, JavaScript/Python code nodes, and AI nodes built on LangChain. Note: Sustainable Use License (fair-code, not OSI open source) — internal use is free, but hosting for customers requires a commercial license .

- **[Activepieces](https://github.com/activepieces/activepieces)**  
  MIT-licensed, AI-native automation platform with 23k+ stars. Clean UI, 200+ integrations, MCP server support for AI agents. The most direct one-to-one open source alternative to n8n for teams who need OSI-approved licensing. Enterprise features sit outside the MIT grant .

- **[Sim](https://github.com/simstudioai/sim)**  
  Open-source workspace for building, deploying, and orchestrating AI agents with 29,493 stars. Visual workflow builder, conversational chat interface, and code-based agent definitions in one platform. 1,000+ integrations, local model support via Ollama/vLLM, Apache 2.0 licensed with Docker Compose self-hosting .

- **[Windmill](https://github.com/windmill-labs/windmill)**  
  Developer-first automation platform where you write scripts in Python, TypeScript, Go, Bash, or SQL. Auto-generates UIs from function parameters, with built-in approval flows and Git sync. AGPLv3 licensed. Ideal for teams wanting code + real ops, not a pure node canvas .

- **[Temporal](https://github.com/temporalio/temporal)**  
  Durable workflow execution engine for developers building mission-critical async operations. Workflows survive crashes and resume from exact failure points. Supports Go, Java, Python, TypeScript, PHP, .NET SDKs. MIT-licensed self-hosted; used by Stripe, Netflix, Snap .

- **[Prefect](https://github.com/PrefectHQ/prefect)**  
  Python-native data workflow orchestration for ETL pipelines, ML retraining, and analytics. Apache 2.0 licensed with built-in retries, caching, concurrency limits, and observability. Best for data engineering teams running scheduled analytics workflows .

- **[Node-RED](https://github.com/node-red/node-red)**  
  Flow-based programming environment from IBM, Apache 2.0 licensed, with 4,000+ community nodes. Excels at IoT, MQTT, and edge device automation. Not a SaaS integration platform — best for event-driven and hardware-adjacent workflows .

- **[AutoGPT](https://github.com/Significant-Gravitas/AutoGPT)**  
  Open-source autonomous agent framework with graphical block editor and marketplace. Bring your own LLM API keys and host the runtime. Free and open-source, total control, but high learning curve and ecosystem churn .

- **[CrewAI](https://github.com/crewAIInc/crewAI)**  
  Python framework for orchestrating multiple specialized agents (researcher, writer, editor, etc.). Free core with managed Enterprise tier for observability and deployment. Best-in-class multi-agent primitives, but code-only with no visual builder .

- **[ByteChef](https://github.com/bytechef/bytechef)**  
  Open-source low-code API integration and workflow automation platform. Can be embedded into SaaS products, enabling customers to connect apps. 758 stars .

- **[LoomFlow](https://github.com/banmu123/LoomFlow)**  
  Lightweight AI-native workflow builder for individuals and small teams. Describe your idea in natural language, get a runnable workflow on a visual canvas, publish as API. One-command Docker self-hosting. Open-source alternative to Dify/n8n .

- **[HumAInFlow](https://github.com/humainflow/humainflow)**  
  Research-grade platform for designing, simulating, and executing GenAI-enabled workflows with explicit human-in-the-loop nodes. Pure Python, SDK-agnostic, supports local and remote LLMs, MCP-compatible. MIT licensed .

### Additional Strong Open-Source Options

- **Huginn** — MIT-licensed agent-based automation for web monitoring and scraping. Mature but development stalled since 2022 .
- **Automatisch** — Simplest open-source Zapier clone with familiar interface for basic automation needs .
- **Obsei** — Low-code AI-powered automation for collecting, analyzing, and disseminating unstructured data from various sources .
- **Multi-Agent Orchestrator** — Open-source AI orchestrator replacing enterprise tools, with 8 autonomous agents and Vision-to-Code capabilities .
- **p9p (Pipeline 9 Platform)** — Open-source automation alternative to n8n with "free forever, no betrayal" positioning .

**Frameworks for building custom agent workflow platforms**: Combine **Dify** for LLM app platform capabilities (RAG, agents, observability), **n8n** or **Activepieces** for integration breadth, **Sim** for multi-modal agent orchestration, and **Temporal** for durable execution of mission-critical async workflows. For code-first teams, **Windmill** provides script-based automation with auto-generated UIs. For pure multi-agent research, **CrewAI** and **AutoGPT** offer Python-native frameworks with maximum control.
